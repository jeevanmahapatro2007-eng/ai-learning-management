About

A learning platform that plots a path, not a playlist.

Most learning platforms show every student the same catalog in the same order. Lodestar takes a different approach: it treats your skill assessments, quiz performance and stated interests as navigation data, and continuously recalculates the most useful next step for you specifically.

Skill-based

Every quiz question is tagged to a skill. Your proficiency per skill updates after every attempt.

Explainable

Every recommendation comes with a plain-language reason — never a black box.

Role-based

Students, instructors and admins each get a dashboard built around what they actually need to do.

Built for learning, not for show

Lodestar is a full-stack Django project: custom authentication and roles, a course and quiz engine, a rule-based recommendation system, gamification, and platform analytics — all built from scratch with an original visual identity.
